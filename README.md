# Social Network Recommendation System

A Python project that cleans social network data and recommends:

- 👥 People You May Know
- 📄 Pages You Might Like

## Features

- Removes empty users
- Removes duplicate friends
- Removes inactive users
- Removes duplicate pages
- Friend recommendation using mutual friends
- Page recommendation using common interests

## Technologies Used

- Python
- JSON
- Dictionary
- Set
- Sorting Algorithms

## Project Structure

```
Social-Network-Recommendation-System/
```

## How to Run

```bash
git clone https://github.com/omkar-zite/social-network-recommendation-system.git

cd social-network-recommendation-system

python social_network.py
```
